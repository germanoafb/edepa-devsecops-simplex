T3 — Upload de arquivo
Objetivo: receber um arquivo enviado pelo usuário, como um laudo técnico ou uma planilha de lote, e salvá-lo na pasta uploads do servidor.

Vamos considerar que o arquivo recebido possui a interface de um objeto de upload do Flask (FileStorage).

```python
import os
import uuid
from pathlib import Path


def upload_arquivo(arquivo):
    try:
        pasta_upload = Path("uploads")
        pasta_upload.mkdir(parents=True, exist_ok=True)

        extensoes_permitidas = {".pdf", ".xlsx", ".csv"}

        extensao = Path(arquivo.filename).suffix.lower()

        if extensao not in extensoes_permitidas:
            return "Formato de arquivo não permitido."

        if not arquivo.filename:
            return "Nome de arquivo inválido."

        nome_arquivo = f"{uuid.uuid4().hex}{extensao}"

        caminho = pasta_upload / nome_arquivo

        arquivo.save(caminho)

        return f"Arquivo salvo com sucesso: {caminho}"

    except (OSError, AttributeError) as erro:
        return f"Erro no upload: {erro}"
```

Como funciona?
  1. Cria a pasta uploads, caso ela não exista.
  2. Verifica a extensão do arquivo.
  3. Gera um nome aleatório utilizando UUID.
  4. Salva o arquivo no servidor.
Observação de segurança: em produção, também devemos limitar o tamanho do arquivo, validar seu conteúdo real (não apenas a extensão) e restringir o acesso à pasta de uploads.
