T4 — Teste de conectividade
Objetivo: testar a comunicação com um equipamento de campo, como um sensor ou controlador utilizado no processo de secagem de grãos.

Vamos utilizar o comando ping por meio da biblioteca subprocess.

```python
import subprocess
import ipaddress


def testar_conectividade(endereco):
    try:
        ipaddress.ip_address(endereco)

        resultado = subprocess.run(
            ["ping", "-c", "4", endereco],
            capture_output=True,
            text=True,
            timeout=10
        )

        if resultado.returncode == 0:
            return "Equipamento conectado!"

        return "Equipamento não respondeu ao ping."

    except ValueError:
        return "Endereço IP inválido."

    except subprocess.TimeoutExpired:
        return "Tempo limite de conexão excedido."

    except OSError as erro:
        return f"Erro ao executar ping: {erro}"
```

Como funciona?
  - ipaddress.ip_address(): verifica se o endereço informado é um IP válido.
  - subprocess.run(): executa o comando no sistema operacional.
  - -c 4: envia quatro pacotes ICMP no Linux.
  - timeout=10: limita a execução a dez segundos.
  - returncode: indica se o comando foi executado com sucesso.
Essa implementação considera endereços IPv4 e IPv6 válidos, mas o parâmetro -c é específico do ping utilizado em Linux.
