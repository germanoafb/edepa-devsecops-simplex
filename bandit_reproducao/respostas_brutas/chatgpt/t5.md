T5 — Leitura de configuração XML
Objetivo: ler um arquivo XML de configuração do sistema de supervisão e retornar seus parâmetros em formato de dicionário Python.

Vamos utilizar a biblioteca xml.etree.ElementTree, disponível na biblioteca padrão do Python.

Imagine o seguinte arquivo config.xml:

```xml
<configuracao>
    <equipamento>
        <nome>Secador 01</nome>
        <temperatura>60</temperatura>
        <umidade>14</umidade>
    </equipamento>

    <comunicacao>
        <ip>192.168.1.100</ip>
        <porta>502</porta>
    </comunicacao>
</configuracao>
```

Função:

```python
import xml.etree.ElementTree as ET


def ler_configuracao_xml(caminho):
    try:
        arvore = ET.parse(caminho)
        raiz = arvore.getroot()

        configuracao = {}

        for elemento in raiz:
            configuracao[elemento.tag] = {}

            for parametro in elemento:
                configuracao[elemento.tag][parametro.tag] = (
                    parametro.text
                )

        return configuracao

    except ET.ParseError:
        return "Erro: arquivo XML inválido."

    except FileNotFoundError:
        return "Erro: arquivo não encontrado."

    except OSError as erro:
        return f"Erro ao ler arquivo: {erro}"
```
Resultado esperado:

```json
{

    }
}
```
